# O Dia a Dia de um QA: A Prática de Testes Manuais Funcionais

Projeto desenvolvido para o desafio da **[Digital Innovation One (DIO)](https://www.dio.me/)**, com o objetivo de simular o dia a dia de um QA aplicando a prática de testes manuais funcionais.

## 🎯 Objetivo

Documentar todo o fluxo de testes manuais funcionais utilizando como sistema-alvo o site **[Swag Labs](https://www.saucedemo.com/)**, desde o planejamento até a criação de casos de teste, cenários BDD e reports de bugs.

## 🧪 Sistema Testado

**Swag Labs** - Loja online para prática de testes automatizados e manuais.  
URL: [https://www.saucedemo.com/](https://www.saucedemo.com/)

## 📁 Estrutura do Repositório

```text
dio-qa-testes-manuais-funcionais/
├── 01-Historias-de-Usuario/   # Histórias de usuário com critérios de aceite
├── 02-Mind-Map/               # Mapa mental dos fluxos testados
├── 03-Cenarios-de-Teste/      # Cenários em Gherkin (BDD)
├── 04-Casos-de-Teste/         # Casos de teste manuais detalhados
├── 05-Planejamento/           # Plano de testes
└── 06-Report-de-Bugs/         # Relatórios de bugs encontrados
```

## 📋 Documentação

| Pasta | Descrição |
|---|---|
| [01-Historias-de-Usuario](./01-Historias-de-Usuario/) | Histórias de usuário no formato "Como/Quero/Para" com critérios de aceite. |
| [02-Mind-Map](./02-Mind-Map/) | Mapa mental representando os principais fluxos e regras do sistema. |
| [03-Cenarios-de-Teste](./03-Cenarios-de-Teste/) | Cenários de teste escritos em linguagem Gherkin (Dado/Quando/Então). |
| [04-Casos-de-Teste](./04-Casos-de-Teste/) | Casos de teste manuais com pré-condição, passos, dados, resultado esperado e status. |
| [05-Planejamento](./05-Planejamento/) | Plano de testes com escopo, critérios, massa de teste e riscos. |
| [06-Report-de-Bugs](./06-Report-de-Bugs/) | Bug reports com severidade, prioridade, passos para reproduzir e evidências. |

## 🛠️ Ferramentas Utilizadas

- **[Jira](https://www.atlassian.com/br/software/jira)** - Gerenciamento de histórias de usuário e bugs
- **[Confluence](https://www.atlassian.com/br/software/confluence)** - Documentação e colaboração
- **[XMind / MindMeister](https://xmind.app/)** - Criação do mapa mental
- **Gherkin / BDD** - Escrita de cenários
- **Markdown** - Documentação

# Mapa Mental - Swag Labs

## Ferramentas para criação
Recomendo utilizar uma das seguintes ferramentas para criar o mapa mental visual:

- [XMind](https://xmind.app/) - Gratuito e muito utilizado
- [MindMeister](https://www.mindmeister.com/) - Online e colaborativo
- [Markmap](https://markmap.live/) - Gera mapa mental a partir de Markdown
- [GitMind](https://gitmind.com/) - Gratuito online

## Estrutura sugerida para o mapa mental

```
SWAG LABS
│
├── LOGIN
│   ├── Usuários Válidos (standard_user, performance_glitch_user, etc.)
│   ├── Usuário Bloqueado (locked_out_user)
│   └── Validações de Campos
│
├── CATÁLOGO DE PRODUTOS
│   ├── Listagem
│   ├── Filtros/Ordenação (A-Z, Z-A, Lo-Hi, Hi-Lo)
│   └── Detalhes do Produto
│
├── CARRINHO
│   ├── Adicionar Item
│   ├── Remover Item
│   ├── Quantidade
│   └── Continuar Comprando
│
└── CHECKOUT
    ├── Informações (First Name, Last Name, Zip)
    ├── Visão Geral (Overview)
    ├── Finalização (Finish)
    └── Confirmação (Thank you for your order!)
```

## Sugestão de arquivo
Salve o mapa mental neste diretório com o nome:
`mapa-mental-swaglabs.png` ou `mapa-mental-swaglabs.xmind`

**Dica:** Crie o mapa mental com essas ramificações e adicione ao repositório para deixar a entrega completa!
